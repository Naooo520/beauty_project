# 酸類保養產品價格分析與預測

## 專案介紹

近年保養品市場逐漸出現成分導向的趨勢，消費者在選擇產品時，也越來越重視產品中的實際成分與濃度。
本專案最初以杏仁酸產品作為資料蒐集對象，但在蒐集過程中發現，市面上的酸類保養產品種類很多，例如杏仁酸、甘醇酸、水楊酸、乳酸及複合酸產品等，而且不同酸類之間的使用目的也有部分重疊，因此後續將資料範圍擴展至市面上較常見的酸類保養產品。
同時也發現，即使是相似酸類、濃度或用途的產品，售價仍可能有明顯差異，因此希望透過資料整理與機器學習模型，分析產品特徵與售價之間的關係。

## 分析流程

1. 蒐集酸類保養產品資料
2. 使用試算表整理與篩選資料
3. 將整理完成的資料下載為 CSV
4. 使用 pandas 將 CSV 匯入 Python
5. 將資料分為 Training Set 與 Validation Set
6. 檢查並處理缺失值
7. 將類別型資料使用 One-Hot Encoding 轉換
8. 建立 Decision Tree 模型
9. 比較不同 `max_depth` 的 MAE
10. 使用 NMF 進行特徵降維
11. 使用 Linear Regression 建立價格預測模型
12. 使用 MAE 比較模型預測結果

## 模型結果

本專案比較兩種價格預測方式：

| 模型 | 最佳 MAE |
| --- | ---: |
| Decision Tree | 180.14 |
| NMF + Linear Regression | 300.84 |

Decision Tree 測試不同的 `max_depth` 後，本次資料中較佳的設定為：`max_depth = 40`

最終 Decision Tree 的 MAE 約為 **180.14**，低於 NMF + Linear Regression 的 **300.84**。

MAE 越低代表模型預測價格與實際價格之間的平均誤差越小，因此在本次資料與分析方法下，Decision Tree 的預測誤差較低。

---

### 決策樹進一步分析

進一步針對 Decision Tree 的特徵重要度進行分析後發現：

| 特徵 | 重要度 |
| --- | ---: |
| 品牌 | 62.24% |
| 容量(ml) | 14.36% |
| 品名 | 6.88% |
| 品牌國家 | 3.52% |
| 品名長度 | 2.82% |
| 次酸% | 2.62% |
| 主酸% | 2.16% |
| 次酸類 | 1.82% |

其中「品牌」為模型最重要的預測變數，重要度約為 **62.24%**，其次為「容量」約 **14.36%** 以及「品名」約 **6.88%**。

此結果表示決策樹在預測產品售價時，主要依賴品牌、容量與產品本身的資訊進行價格區分，而酸類濃度與酸類種類的相對重要度較低。

不過，品牌的重要度較高並不代表品牌造成模型的預測誤差，而是代表品牌對於模型區分不同產品售價具有較高的判別能力。

---

### 預測誤差分析

原先推測模型的 MAE 約為 **180.14**，可能主要受到高價品牌或高價產品影響，因此進一步依照不同售價區間觀察預測誤差。

| 售價區間 | 商品數量 | MAE | 誤差貢獻率 |
| --- | ---: | ---: | ---: |
| 0～500 | 106 | 117.39 | 27.63% |
| 501～1000 | 88 | 164.06 | 32.06% |
| 1001～1500 | 37 | 310.82 | 25.54% |
| 1501～2000 | 7 | 487.00 | 7.57% |
| 2001～3000 | 3 | 117.44 | 0.78% |
| 3000以上 | 9 | 321.60 | 6.43% |

分析結果顯示，模型誤差並非單純集中於高價產品。

雖然部分中高價區間具有較高的單筆 MAE，但 **1500 元以下商品合計約占 85% 的總預測誤差**，主要原因與該價格區間的商品樣本數較多有關。

因此，本次模型的整體 MAE 並不能單純解釋為「高價商品造成較大的誤差」，而應視為各價格區間的 **樣本數量與單筆預測誤差共同作用的結果**。

此外，部分品牌的樣本數較少，而品牌、品名等類別型特徵經 One-Hot Encoding 後產生大量特徵，可能使模型較難穩定學習各品牌的價格規律，進而造成部分商品的預測誤差較大。

### 分析結論

綜合上述結果，本次 Decision Tree 模型顯示：

- 品牌是預測杏仁酸產品售價時最重要的特徵。
- 容量與品名同樣具有一定的價格判別能力。
- 酸類濃度與酸類種類對模型的相對影響較低。
- 預測誤差並非主要來自高價商品，而是受到樣本數量與個別商品預測誤差共同影響。
- 部分品牌樣本較少，可能限制模型學習其穩定價格規律的能力。

因此，本次分析顯示杏仁酸產品售價並非僅由成分濃度決定，品牌、容量及產品定位等資訊在模型中具有更明顯的價格區辨能力。
